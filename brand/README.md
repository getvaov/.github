# VAOV Brand Assets

Exported from the `vaov-branding` Figma file (page 1). Every file has a transparent
background and is generated from the vector layers, so the artwork sits cleanly on
any surface.

**The colour in a file name is the colour of the mark, not of the background.**
Use `*-white-*` on dark surfaces and `*-black-*` on light ones.

## Notes

- Prefer the SVG wherever the target supports it; the PNGs are there for places that
  do not (app stores, email, chat avatars).
- Do not recolour, rotate, stretch or add effects to the mark. If you need a colour
  that is not here, ask first.
- The app icons are raster only — the tile uses a gradient fill that does not survive
  a vector export cleanly.

Need a size or a format that is not here? Open an issue in this repo.
